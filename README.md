# BluePulse

Real-Time Bluetooth Low Energy (BLE) Proximity Tracker & Radar Visualization mobile application built with Flutter.

## Overview

BluePulse is designed for high-performance mobile tracking, proximity calculation, and radar-style visual scanning across Android and iOS platforms.

- **Target Platforms:** Android & iOS (Mobile Only)
- **Application ID:** `com.bluepulse.app`
- **Architecture:** Clean Architecture & Feature-Driven Structure

## Getting Started

### Prerequisites
- Flutter SDK `^3.47.2` (Dart `^3.13.2`)
- Android Studio / Xcode configured for mobile builds

### Run locally
```bash
# Fetch dependencies
flutter pub get

# Run test suite
flutter test

# Run application on connected mobile device or emulator
flutter run
```
